# Campus Coin

Student budget & expense tracker UI — **Smart Spending, Student Style.**

Built with React + Vite + Tailwind CSS + React Router + Recharts, mapped to the Campus Coin SRS (NextGen BudgetBee / End-to-End Web Solutions).

## Run locally

```bash
cd campuscoin
npm install
npm run dev
```

Open the URL shown in the terminal (usually http://localhost:5173).

## Demo personas

Use the top bar to switch:

| Persona | Entry |
|---------|--------|
| Public | Landing, sitemap, auth |
| Student | `/app` — dashboard, transactions, categories, budgets, reports, insights, profile |
| Admin | `/admin` — users, categories, announcements, stats |
