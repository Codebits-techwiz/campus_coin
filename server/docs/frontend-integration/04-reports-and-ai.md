
# 04 Reports & AI

## Reports (Student)
All report GET routes take optional `?dateFrom=...` and `?dateTo=...` query params.

### GET `/api/reports/category-breakdown`
- **Success (200):** Array of `{ _id: categoryId, name: "Food", total: 450.00 }` (good for Pie Charts).

### GET `/api/reports/trend-6months`
- **Success (200):** Array of `{ _id: "2026-09", income: 1500, expense: 500 }` (good for Bar/Line Charts).

### GET `/api/reports/daily-weekly`
- **Success (200):** `{"dailyAverage":15.00,"weeklyAverage":105.00}`

### GET `/api/reports/export-pdf`
- **Purpose:** Returns raw binary PDF stream.
- **UI Behavior:** Use `window.open()` or Blob download to let the user save the file.

### POST `/api/reports/share-email`
- **Payload:** `{"recipientEmail":"parent@example.com","month":"2026-09"}`

## AI (Student)
**UI Note:** The frontend should subtly show an advisory notice like *"AI insights are generated by an LLM and may not be 100% accurate."*

### POST `/api/ai/predict-category`
- **Purpose:** Suggest category while user types a transaction description.
- **UI Behavior:** Call this with a 500ms debounce.
- **Payload:** `{"description": "Uber ride"}`
- **Success (200):** `{"data":{"suggestedCategoryId":"6ab...","categoryName":"Transport","icon":"🚌","color":"#2196f3","confidence":0.6,"source":"naive_bayes_ai"}}`

### POST `/api/ai/feedback`
- **Purpose:** If the AI suggested Transport, but the user overrides it to Entertainment, call this.
- **Payload:** `{"description":"Uber ride","correctedCategoryId":"..."}`

### GET `/api/ai/monthly-insights`
- **Purpose:** Generate narrative summary and tip text. The UI MUST display the `disclaimer` text prominently to advise the user.
- **Success (200):** `{"data": {
      "month": "2026-09",
      "source": "template",
      "summaryText": "In 2026-09, your spending in Food rose sharply by 1778% compared to your 3-month average.",
      "tipText": "Try setting a weekly cap of $25 on Food to get your spending back on track.",
      "disclaimer": "Notice: This insight is an advisory suggestion generated based on your spending patterns, not certified financial advice."
    }}`. *(Note: source might be 'template' if Gemini is down. The UI can display a fallback badge).*

### GET `/api/ai/saving-tips`
- **Purpose:** Get 3 actionable tips.
- **Success (200):** Array of `{_id: "...", text: "...", isPinned: false}`.

### POST `/api/ai/saving-tips/:id/pin` & `/dismiss`
- **Purpose:** Pin a tip so it stays visible, or dismiss it permanently.

### GET `/api/ai/monthly-insights/history`
- **Purpose:** Get a list of past insights.
- **Success (200):** Array of past insight objects.
